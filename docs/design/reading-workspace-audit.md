## Rendering contract

`reading-workspace.spec.ts` bundles the actual full App and exact comparison trees with the same synthetic demo data. The third tree is immutable competing PR #1469 head `66d75a22a8a6b44542cbdbaaabc0b27b19053b7e`; it is rendered for comparison, not incorporated. PR runs use their exact base; the conflict-comparison branch run uses original UI base `0ec554009806d9d7ad263a7f1ac41240b59b1148`; ordinary master runs use the available immediate parent. Each CSS compilation scans its actual source tree.

No Next server, signed-in account, production bindings, persistent browser storage or external API access is used. The isolated navigation adapter preserves the real mobile history hooks but does not establish complete Next server routing. All unexpected network requests fail the test. Images are local deterministic placeholders. CI supplies the public CSS/woff2 assets from its already-required production build. Only font-face rules and font variables are extracted; baseline/candidate/alternative layout font definitions must be identical. Font readiness and loaded faces are checked. Local fixture compilation can use explicitly labeled system fallback; CI cannot silently do so.

Before/after/alternative navigation, list and reader screenshots are native Chromium viewport captures. Additional filter, display, empty-search and settings captures contain product UI only. Source/font provenance and actual computed-color contrast are attached. Native Space activation is tested with a mounted desktop reader, as are browser Back/Forward, tag/collection scopes, long-library pinned subscription search, a 150px sidebar and enlarged text. Existing aggregate CI and all relevant component interactions remain required at the final head. Draft publication is not completion; final screenshots, CI and independent review must be inspected before merge eligibility is reported.

## Scope and rollback

Only reading navigation, task grouping, labels and their tests change. Authentication, APIs, data structures, notification permissions, model choices and production settings remain untouched. Serena removal and Codex/README modernization have separate PRs. Revert the UI commit to restore the old presentation without a data migration. Existing production holds remain in force.
