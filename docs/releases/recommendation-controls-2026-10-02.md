# 記事のおすすめ理由と話題の調整 — 2026-10-02

### 激アツ新機能っ

- **「なぜおすすめ？」が見えるよ〜！** — 新しさ・閲覧や保存とのカテゴリ一致・スター設定・配信元の偏りまで、実際の選び方を確認できるよっ。公開日時がない記事は取得日時として説明するから、新着と勘違いしないよ〜🔎📖
- **好きな話題を自分で調整っ！** — 「この話題を増やす・減らす」でこのブラウザのおすすめ順位を調整できるよ〜。「標準に戻す」・直前の取り消し・全リセットもあって、気軽に試せちゃう✨🎀
- **ドパガキでも理由をチェックっ！** — 理由を開いている間は再生を止め、戻ると同じカードと再生設定を保つよっ。調整は次の補充記事から反映して、読んでいる途中に記事が飛ばないよ〜📱✨
