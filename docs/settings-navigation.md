# 設定のカテゴリと検索

設定画面は、次の目的別カテゴリで切り替えられます。

| カテゴリ           | 設定の目的                                                                |
| ------------------ | ------------------------------------------------------------------------- |
| 読書・表示         | フォントサイズ・書体・行間・本文の幅・両端揃え・プリセット・自動既読      |
| ギャラリー         | 通常/フォーカス時の列数・カード・最小画像・自動スクロール・ページ件数     |
| 読み上げ           | 対応するエンジン・ボイス・音量                                            |
| AI・翻訳           | 実行先・自動翻訳/要約・端末のみの自動処理・クラウドモデル                 |
| 通知               | おすすめ/エラー通知・配信時刻・サイレント時間帯・タイムゾーン             |
| フィード管理       | 登録数・フィードの健全性                                                  |
| 保存・共有         | 記事保持期間・重複非表示・画像フォルダー・ヘッダーのシェア先              |
| バックアップ・連携 | OPML・保存済み検索条件・メモ・記事状態・コレクションの入出力と SingleFile |

## 検索とキーボード操作

- 「設定を検索」で項目名・説明・別名を検索します。例: `文字サイズ`、`TTL`、`TTS volume`、`OPML`。全角英字や全角スペースにも対応します。
- 複数語はすべての語を含む項目を表示します。一致しない場合は短い言葉や別名を試してください。
- 検索しているだけではカテゴリや保存値は変わりません。結果を選ぶと、そのカテゴリへ移動して実際の設定へフォーカスします。
- 現在の設定やブラウザの対応状況により利用できない項目は、その説明とカテゴリを表示します。有効化や設定変更を自動で行うことはありません。
- カテゴリは左右矢印、Home / End で切り替えられます。Tab / Shift+Tab で設定内を移動し、Escape で閉じます。
- 本文内の「読書設定」では、日常的な文字・本文の幅・テーマをその場で調整できます。通常の設定と保存値を共有します。

## 実装と配置のルール

- `UserSettingsModal.tsx`: 既存の共有設定コントローラーを使い、検索先の表示とフォーカスを調整します。
- `user-settings/SettingsNavigation.tsx`: roving tabs とローカル検索の UI です。
- `user-settings/SettingsCategoryPanel.tsx`: パネルをアンマウントせず、目的カテゴリごとの表示を切り替えます。
- `user-settings/settings-catalog.ts`: 固定のラベル・説明・別名と検索先です。記事・保存値・プリセット名・ユーザーデータは検索対象に含めません。
- 新しい設定は目的に合うカテゴリへ一度だけ配置し、静的な検索先と inventory test を一緒に追加します。日常の文字設定は読書・表示へ、低頻度の音声・AI・通知・保存・入出力設定はそれぞれの目的カテゴリへ置きます。
- 既存の設定値・保存キー・記事保持期間の `null`（既定）と `0`（無制限）・プリセット・入出力の意味は変えません。
- 検索や移動は AI 実行・全文取得・通知購読の変更を行いません。カテゴリの通常表示に必要な読み取り専用の状態確認は既存のライフサイクルを維持します。
