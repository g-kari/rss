# キーボードショートカット

RSS Reader の主要な操作はすべてキーボードから実行できる。
アプリ内では `?` キーを押すとヘルプモーダルが開く。

> Single source of truth: [`src/config/shortcuts.ts`](../src/config/shortcuts.ts)
> 新しいショートカットを追加するときは、まず `SHORTCUTS` 配列を更新すること。
> `KeyboardShortcutsModal` と本ドキュメントの両方が同じ定義を参照する想定。

## 発動条件の共通ルール

- `<input>` / `<textarea>` にフォーカスがあるときはグローバルショートカットを無効化する（検索欄・ノート編集欄など）。
- 一部のキー（`v` / `a` / `P` / `Space` など）は **記事表示ペイン（ArticleView）** で記事が選択されているときだけ動作する。

## 記事ナビゲーション

| キー      | 動作               | 備考                                                                        |
| --------- | ------------------ | --------------------------------------------------------------------------- |
| `j` / `↓` | 次の記事へ         | 移動先の記事は自動的に既読化される                                          |
| `k` / `↑` | 前の記事へ         | 先頭のときは動作しない                                                      |
| `n`       | 次の未読記事へ     | 現在位置より後方の未読を探す                                                |
| `p`       | 前の未読記事へ     | 現在位置より前方の未読を探す                                                |
| `x`       | ランダム未読記事へ | 未読がなければ全記事からランダム。候補が 2 件以上なら現在選択中の記事は除外 |
| `g`       | 先頭の記事へ       | 現在のフィルター条件下の最初の記事                                          |
| `G`       | 末尾の記事へ       | 現在のフィルター条件下の最後の記事                                          |

## 記事操作

| キー            | 動作                     | 備考                                               |
| --------------- | ------------------------ | -------------------------------------------------- |
| `o`             | 元記事を開く             | 新規タブで開く                                     |
| `v`             | 全文を取得               | 記事表示中のみ。取得済・取得中は無効               |
| `a`             | AI 要約の表示 / 解除     | 記事表示中のみ                                     |
| `P`             | 読み上げ開始 / 停止      | 記事表示中のみ。Web Speech API 非対応環境では無効  |
| `Space`         | 記事本文を下にスクロール | 記事表示中のみ。ビューポートの 80% ぶん            |
| `Shift + Space` | 記事本文を上にスクロール | 記事表示中のみ                                     |
| `b`             | ブックマーク切替         | 記事選択中のみ                                     |
| `L`             | いいね切替               | 記事選択中のみ                                     |
| `t`             | リーディングリスト切替   | 記事選択中のみ。トースト通知あり                   |
| `r`             | 既読 / 未読切替          | 記事選択中のみ                                     |
| ~~`z`~~         | ~~スヌーズ（期間選択）~~ | #619 で UI からオミット。バックエンド実装は残置    |
| `e`             | 現在記事より上を全既読   | 現在の記事を含む。件数をトースト通知               |
| `m`             | 全既読にする             | 選択中フィードの全記事を既読化                     |
| `c`             | リンクをコピー           | `navigator.share` 対応環境では共有ダイアログを開く |
| `C`             | Markdown リンクをコピー  | `[title](url)` 形式                                |

## フィルター・表示切替

| キー | 動作                             | 備考                                          |
| ---- | -------------------------------- | --------------------------------------------- |
| `u`  | 未読フィルター切替               |                                               |
| `B`  | ブックマークフィルター切替       |                                               |
| `T`  | リーディングリストフィルター切替 |                                               |
| `I`  | いいねフィルター切替             |                                               |
| `0`  | すべてのフィルターを解除         | 検索・状態・日付などを初期状態に戻す          |
| `D`  | ダイジェストモード切替           | 全フィード表示時にフィードごと最新 3 件に制限 |
| `d`  | 日付フィルター循環               | 期間を循環（全期間 / 今日 / 今週 など）       |
| `w`  | 読了時間フィルター循環           | 短い / 中程度 / 長い を循環                   |
| `s`  | ソート順切替                     | 降順 ↔ 昇順                                   |
| `f`  | フォントサイズ循環               | small → medium → large                        |
| `F`  | フォントファミリー循環           | ゴシック → 明朝 → 等幅                        |
| `l`  | レイアウト循環                   | リスト / グリッド等                           |

## 検索・フィード操作

| キー                  | 動作                         | 備考                                                   |
| --------------------- | ---------------------------- | ------------------------------------------------------ |
| `/` / `Ctrl+K` / `⌘K` | 検索欄にフォーカス           |                                                        |
| `]`                   | 次のフィードへ               | ピン留めフィード優先の順序。末尾なら先頭に循環         |
| `[`                   | 前のフィードへ               | 循環する                                               |
| `q`                   | フィードクイックスイッチャー | モーダルで ↑ / ↓ / Enter / Escape による高速切替       |
| `F5`                  | フィードを更新               | 選択中フィードがあれば単体更新、なければ全フィード更新 |

## モーダル・グローバル

| キー     | 動作                              | 備考                                     |
| -------- | --------------------------------- | ---------------------------------------- |
| `?`      | このヘルプを表示 / 閉じる         |                                          |
| `,`      | ユーザー設定を表示 / 閉じる       |                                          |
| `\`      | フォーカスモード切替              | 記事ペインのみ全画面表示                 |
| `Escape` | モーダルを閉じる / 編集キャンセル | ヘルプ・クイックスイッチャー・検索欄など |

### モーダル内の専用キー

- **フィードクイックスイッチャー**: `↑` / `↓` でカーソル移動、`Enter` で選択、`Escape` で閉じる
- **フィード / 記事タイトル編集**: `Enter` で保存、`Escape` でキャンセル
- **キーワードフィルター編集（タグ入力）**: `Enter` / `,` でタグ追加、入力が空の状態で `Backspace` で末尾タグ削除
- **画像ライトボックス**: `←` / `→` で画像移動、`Escape` で閉じる
- **記事検索欄**: `Enter` で検索履歴に追加（2 文字以上）、`Escape` で検索クリアしフォーカスを外す
