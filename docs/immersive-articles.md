# ドパガキモード

記事一覧の「いま読むおすすめ」から明示的に起動する、縦スワイプ用の全画面表示。個別フィード、検索、日付・読了時間・保存状態、グループ・タグ・コレクション、画像・動画・SNS の各ビューでも、現在の条件を保ったまま使える。

- 読み込み済みの候補だけを、既存のローカル推薦順位付けで最大10件選ぶ。候補は同じ厳密なフィルター・NSFW・ミュート・既読期限・「興味なし」を守る
- 同じセッションの次バッチには、すでに提示した記事 ID と同じリンクの記事を含めない。自動追加やページの先読みはしない
- 最後に必ず区切り画面を表示し、「次の10件を見る」の明示操作でのみ続く。候補が尽きたら一覧へ戻れる
- サムネイルは既存 OGP キャッシュ・記事画像・既存フォールバックから。ショート表示だけでは本文抽出・AI 要約/翻訳は起動しない。読み込み済みのネイティブ動画は音声なしで再生し、再生できない場合は記事タイマーへフォールバックする。説明は既存 summary/content をプレーンテキストにして240文字まで
- 移動はブラウザ標準の縦スクロール＋スナップ、↑↓/PageUp/PageDown、前後ボタンに対応。長いカードの内部はスクロールできる。プログラム移動は即時で、reduced motion でもアニメーションしない
- 起動・移動・終了は既読や閲覧履歴を書き換えない。「本文を読む」で既存リーダーの選択処理に渡し、その後は既存の既読設定に従う
- 「後で読む」は既存ハンドラ、「興味なし」は既存の30日間非表示/通知ON時のみ同期するハンドラを共有。取り消しできる
- バッチ順は保存などの操作で並べ替えない。ただし表示中の記事が既読/非表示/フィルター対象外になれば、古い内容を表示せず対象外カードに置き換える
- Escape と「一覧に戻る」で終了。Tab はダイアログ内を循環し、終了時は起動ボタンにフォーカスを戻す。下の一覧はアンマウントせずスクロール位置を保つ
- 検索、個別フィード、各フィルターや別ビューへ変更した場合は開いていたモードを閉じる。新しい条件のおすすめと入口は残り、明示操作で再開できる。勝手に起動しない
- 候補が0件でも入口と理由を表示し、条件外の記事で埋めない。1〜2件ならその件数だけを表示する。読み込み中・読み込み失敗・検索反映中は理由付きで入口を一時停止し、完了後も自動起動しない
- おすすめ候補は現在の一覧の厳密な部分集合。通常リーダーが表示を維持する選択中記事でも、NSFW・キーワード・著者・保存状態・ダイジェスト等の条件に合わなければ候補から除外する
- 所属フィードが0件のグループは空のまま表示し、他のフィードで埋めない。専用ダイジェストフィードでも通常のダイジェスト切り替えと同じ件数制限を守り、選択中記事の表示維持で増えた記事を候補へ混ぜない

## 検証

`src/lib/immersive-articles.test.ts` と `src/components/ImmersiveArticleMode.test.tsx` はバッチ境界、厳密スコープ、連続キー操作、保存/非表示/取り消し、終了とフォーカス、既読・AIなどの副作用がないことを確認する。

`e2e/immersive-articles.spec.ts` は production component/style をローカル fixture で描画し、1280/390/320px、reduced motion、ネイティブ scroll、ライト/ダーク、フォーカスと下の一覧位置を確認する。ブラウザ実行できる環境で別途実行すること。

## 自動再生と端末内ナレーション

- 記事・字幕の有限タイマーは画像ズームの演出とは独立する。メモリ・CPU の軽量表示、データ節約、アニメーション読込失敗でも記事を自動で送る
- reduced motion と明示的な「動き OFF」は最初に一時停止する。再開ボタンは操作可能で、明示的に再開すると画像を動かさず記事・字幕を送る。画像の動きを止めた理由はカードに表示する
- 一時停止は記事移動・タブ非表示/再表示でも維持する。非表示中の時間はタイマーに加算しない。最大10件で区切り、続行は明示操作のみ
- 「読み上げ」はセッションごとに OFF から開始する。押したときだけブラウザの端末内音声（localService=true）を使い、日本語を優先する。日本語がないときは別言語の端末内音声であることを表示し、端末内音声がないときは無音の自動送りを続ける。リモート音声や新規音声サービスへ記事テキストを送らない
- ナレーションは短い発話に分割し、再生速度は次の発話から反映する。一時停止/再開は記事と音声の共通ボタン、読み上げ停止は別ボタン。記事移動・閉じる・フィルター変更では旧発話をキャンセルし、古い完了イベントを無視する
- 記事タイマー/動画とナレーションが両方完了してから次へ進む。音声が開始しない/止まった場合は理由を表示し無音の自動送りへ戻す。通常リーダーの自動読み上げはモード中に割り込まない

## 本文・キュー・画像

- 「ここで読む」はモード内に本文パネルを開く。既存の本文取得 API・キャッシュ・サニタイズ処理を利用し、必要なら全文を一度取得する。失敗時は説明と再試行を表示する。本文を開くだけでは既読・履歴・AI を操作しない
- 本文パネルを開いている間は記事・動画・ナレーションを一時停止する。Escape は本文パネルだけを閉じ、起動したボタンへフォーカスを戻す。閉じたら元の一時停止状態を復元する
- 「本文を読む」は通常リーダーを開き、一度だけの全文表示要求を渡す。グローバルな全文取得設定は変更せず、既存の選択時の既読・履歴処理をそのまま使う。通常ペインとフォーカス時の詳細オーバーレイを区別し、必要な画面だけが要求を消費する
- 現在のバッチの残りを同じフィルター内・同じアカウントの間保持する。「本文を読む」で離れた記事と、その前に通過した記事は再開キューから外し、戻ると残りの次の記事から続ける。これは削除・興味なし・新しい既読処理ではない。アカウント・検索/フィルター/スコープ変更ではキューをリセットし、再開時も厳密な対象条件を確認する
- 画像は OGP・フィード画像に加え、取得済み本文キャッシュと RSS 内の大きな本文画像も候補にする。安全な URL を一つずつ確認し、OGP の表示失敗時は次の候補へ切り替える。認証付き保存画像の既存パスも扱い、無効な内部/プロキシ URL は要求しない。新しい全文や OGP の先読みをこのフォールバックのために行わない
